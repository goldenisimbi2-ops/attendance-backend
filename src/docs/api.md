# Attendance API

Basic documentation for authentication and main endpoints.

Authentication:
- POST /api/auth/register
- POST /api/auth/login
- GET /api/auth/me

Users (admin): /api/users
Classes (admin): /api/classes
Subjects (admin): /api/subjects
ClassSubject (admin): /api/class-subjects
Attendance sessions (teacher/admin): /api/attendance-sessions
Attendance records (teacher/admin): /api/attendance
Students (student): /api/students/me
Teachers (teacher): /api/teachers/me
Dashboard (admin): /api/dashboard

See code for request/response examples.
